# Coding Blog Page

A responsive **Coding Blog Page** created using **HTML5, CSS3, JavaScript, and Bootstrap**. The project provides a clean and responsive interface for presenting coding and technology-related blog content.

## 🚀 Features

* Responsive navigation bar
* Responsive blog layout
* Coding and technology blog sections
* Blog cards with images
* Responsive design for desktop, tablet, and mobile
* Bootstrap-based UI components
* Custom CSS styling
* Custom JavaScript functionality
* Organized project structure
* Image-based blog content

## 🛠️ Technologies Used

1. **HTML5** — Page structure
2. **CSS3** — Custom styling
3. **JavaScript** — Frontend interactions
4. **Bootstrap** — Responsive layout and UI components
5. **Bootstrap Icons** — Icons used in the interface

## 🎨 Bootstrap

Bootstrap is used to create the responsive user interface and layout.

The project uses Bootstrap for components such as:

* Navbar
* Responsive grid
* Cards
* Buttons
* Containers
* Spacing utilities
* Responsive layouts

Bootstrap JavaScript is loaded separately through the Bootstrap CDN, while the project's own JavaScript is maintained in:

```text
js/script.js
```

## ⚙️ JavaScript

Custom frontend JavaScript is maintained separately from Bootstrap:

```text
js/script.js
```

Bootstrap's JavaScript handles Bootstrap components, while `script.js` is used for the project's own frontend interactions.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd Coding-Blog-Page
```

### 3. Run the website

Open:

```text
index.html
```

in your web browser.

For development, you can also use **Live Server** in Visual Studio Code.
